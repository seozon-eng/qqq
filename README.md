# MinLauncher — минимальный лаунчер для Android TV приставки

Тёмный главный экран без рекламы, рекомендаций и аккаунтов. Показывает только те приложения, которые вы выберете. Зависимостей нет, весит почти ничего.

## Как собрать APK (на Mac)
1. Установите Android Studio (бесплатно, developer.android.com/studio).
2. File → Open → выберите папку `MinLauncher`. Дождитесь синхронизации Gradle (нужен интернет).
3. Меню Build → Build Bundle(s) / APK(s) → Build APK(s).
4. Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.

## Как установить на приставку
- Закиньте APK на флешку и откройте на приставке файловым менеджером, либо
- Через ADB: `adb connect <IP приставки>` → `adb install app-debug.apk`
  (отладка по USB/сети включается в Настройки → Об устройстве → 7 раз «Номер сборки» → Для разработчиков).

## Как пользоваться
- При первом запуске видны все приложения. Выберите плитку «Выбрать приложения», отметьте нужные (✔) и нажмите «Готово». Остальные пропадут с экрана.
- Долгое нажатие OK на приложении — его сведения (удалить, отключить).
- Кнопка «Назад» на главном экране ничего не делает (так и задумано).
- Выбор в «Настройки → Приложения → Приложения по умолчанию → Главный экран» (название пункта зависит от приставки), либо просто нажмите Home и выберите «Мой экран» → «Всегда».

## Важно про «блокировку»
Лаунчер **скрывает** лишнее, но не запрещает его работу: фоновые китайские сервисы и реклама продолжат работать. Чтобы реально отключить ненужные приложения, на компьютере через ADB:

    adb shell pm disable-user --user 0 <имя.пакета>

Вернуть: `adb shell pm enable <имя.пакета>`. Не отключайте системные компоненты (com.android.*, com.google.android.* вслепую), иначе приставка может перестать загружаться; безопаснее отключать по одному и проверять.
